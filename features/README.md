# Scenario documentation

These `.feature` files make the planned cases quick to read and review. They are documentation only; there are no Cucumber step definitions and Gherkin does not run the tests.

- Keep each scenario focused on an observable behavior.
- Mark unverified scenarios `@draft` until the local TestYard preflight confirms the flow and data.
- Implement verified cases separately in Playwright + TypeScript using POM.
- Keep this documentation aligned with the executable tests during review.
